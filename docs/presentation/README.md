# Brink presentation files

This folder contains the final-project presentation in two formats:

- [`html/`](html/) — the current interactive presentation and the recommended version to edit.
- [`brink-deck.pptx`](brink-deck.pptx) — the earlier PowerPoint export.
- [`presentation-spec.md`](presentation-spec.md) — the original presentation requirements and research.
- [`build_deck.py`](build_deck.py) — the script that generated the earlier PowerPoint file.

Start with [`html/README.md`](html/README.md) when changing slides or speaker notes.

The HTML presentation is intentionally stored with its source and screenshots so every team member
can run it locally, make changes on a branch, and submit those changes through a normal pull request.
