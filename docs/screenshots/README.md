# Screenshots

Deliverable screenshots of the live app (https://brink-xg7p.onrender.com), used by the root
`README.md` and the presentation (`docs/presentation/presentation-spec.md`).

Capture with a logged-in account that has real data, and warm the Render instance first (load a
page, wait out the ~50s cold start) so nothing shows a "waking up" screen.

Drop these files here (suggested names):

- `landing.png` — `/`, logged out (hero + feature grid)
- `feed.png` — `/feed`, a card with the Spotify player open + reactions/comments
- `profile-taste.png` — `/u/{other-handle}`, showing the "% compatible" line + taste community
- `artist.png` — `/artist`, an artist account with a behind-the-scenes post
- `analytics.png` — `/analytics`, the tribes / distinctness / audio-DNA view

Optional: `composer-share.png`, `liked-by.png`.
